# 01. 로그인 · 대시보드 (My Projects) 화면 피드백

_작성일: 2026-01-26_


## 1) 로그인 화면 (디자인_피드백.pdf 1p 상단)

### 잘 된 점
- 중앙 카드 정렬 + 여백/그라데이션 배경으로 **집중 포인트가 명확**합니다.
- Primary CTA(로그인)와 Secondary CTA(Google) 구분이 명확합니다.

### 개선 포인트 (UI 디테일)
1. **탭(로그인/회원가입) 상태 대비 강화**
   - 현재도 구분되지만, 탭 인디케이터(underline)만으로는 약할 수 있어요.
   - 제안:  
     - 활성 탭: 굵기 + 컬러 + 하단 인디케이터  
     - 비활성 탭: 회색 + 클릭 가능 커서/호버

2. **입력 필드의 ‘라벨 vs 플레이스홀더’ 역할 분리**
   - 지금처럼 라벨이 있는 구조가 좋습니다. 다만 플레이스홀더는 예시만 남기고,
     에러/가이드 텍스트 영역을 확보하면 완성도가 올라갑니다.
   - 예: 비밀번호 아래에 `8자 이상 · 영문/숫자 조합 권장` 같은 한 줄 가이드(선택)

3. **링크(비밀번호 찾기)의 시각적 우선순위 조정**
   - “로그인 상태 유지” 체크박스와 “비밀번호 찾기”가 같은 레벨로 보이면 시선이 분산됩니다.
   - 제안: 링크는 오른쪽 정렬 유지하되 **텍스트 크기 -1단** + 링크 색상 명확화.

4. **포커스/호버/에러/로딩 상태 정의(필수)**
   - 작업형 툴은 로그인 실패/지연이 실제로 자주 발생합니다.
   - 최소 상태:
     - Focus ring(접근성) / Hover / Disabled / Error(메시지+필드 빨간 테두리) / Loading(버튼 스피너)
   - 에러 문구 예시:
     - `이메일 또는 비밀번호가 올바르지 않습니다. (남은 시도 4회)`  
       → 보안 정책이 없으면 남은 시도는 생략

### 개선 포인트 (UX 플로우)
- **Enter 키 제출**, 비밀번호 보기(eye) 토글, Caps Lock 감지 등 “로그인 기본기” 추가 권장
- Google 로그인 아래 `계속하면 이용약관/개인정보 처리방침에 동의합니다` 같은 최소 법무 문구(필요 시)

## 2) My Projects 대시보드 (디자인_피드백.pdf 1p 하단)

### 첫 인상 진단
- 전체적으로 깔끔하지만, “프로젝트가 0개”일 때 **너무 비어 보입니다.**
- 우측 상단/오른쪽의 `+ New Project` 버튼과 중앙 카드 CTA가 중복되어, 오히려 결정이 늦어질 수 있어요.

### 개선 포인트 (빈 상태 설계)
1. **빈 상태에 ‘한 가지’ 주요 경로만 제시**
   - 제안: Primary CTA는 하나로 통일  
     - `+ 새 프로젝트 만들기` (primary)
   - 카드 영역은 보조 옵션/템플릿으로 구성:
     - “AI 시나리오로 시작” / “빈 프로젝트” / “템플릿에서 시작”
   - 이렇게 하면 사용자의 “첫 성공”이 빨라집니다.

2. **프로젝트가 무엇인지 1~2줄로 정의**
   - 예: `프로젝트는 시나리오-씬-샷-영상 결과물을 한 곳에서 관리하는 작업 공간입니다.`  
   - 대시보드가 “툴 시작점” 역할을 해야 합니다.

3. **샘플 프로젝트/튜토리얼 링크 제공(특히 중요)**
   - “노드 캔버스”는 처음 보는 사용자에게 장벽이 될 수 있어요.
   - 빈 상태에서:
     - `샘플 프로젝트 열기(읽기 전용)`  
     - `3분 튜토리얼 보기`
   - 이 2개만 추가해도 유입 전환율이 달라집니다.

### 개선 포인트 (내비게이션/레이아웃)
1. **좌측 사이드바 아이콘에 툴팁/라벨**
   - 아이콘만 있으면 기능 학습 비용이 큽니다.
   - 최소: hover 시 툴팁, 또는 펼침/접힘 가능한 라벨 모드 제공

2. **상단 검색창의 조건부 노출**
   - 프로젝트가 없을 때는 검색이 무의미합니다.
   - 제안:
     - 0개일 때는 검색창을 “최근 튜토리얼/가이드”로 대체하거나,
     - placeholder를 `프로젝트를 만든 후 검색할 수 있어요`로 안내

3. **‘실시간 협업 시작’ CTA는 위치/맥락 재검토**
   - 프로젝트가 없는 상태에서 협업 버튼이 있으면 “무엇을 협업?”이 됩니다.
   - 제안: 프로젝트 내부(캔버스/타임라인)에서 강조하고, 대시보드에서는 secondary로 낮추기.

### 마이크로카피 제안
- 헤더 문구 아래 서브텍스트:
  - `처음이신가요? 30초 만에 첫 씬을 만들어보세요 →` (튜토리얼 링크)

### 체크리스트 (개발/디자인)
- [ ] 빈 상태 컴포넌트 패턴화(다른 페이지와 재사용)
- [ ] 사이드바 툴팁/라벨
- [ ] Primary CTA 1개 원칙 적용
- [ ] 온보딩 entry 제공(샘플/튜토리얼)
