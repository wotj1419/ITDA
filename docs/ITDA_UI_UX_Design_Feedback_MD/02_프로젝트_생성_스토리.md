# 02. 새 프로젝트 생성 · Story(Scenes) 기본 화면 피드백

_작성일: 2026-01-26_


## 1) 새 프로젝트 만들기 모달 (디자인_피드백.pdf 2p 상단)

### 잘 된 점
- 모달 크기/여백이 안정적이고, 필드가 과하게 많지 않아 시작 장벽이 낮습니다.
- `취소 / 생성` 액션이 우측 하단에 모여 있어 방향성이 명확합니다.

### 개선 포인트 (폼 정보 구조)
1. **필드 그룹핑(필수/선택/AI 관련)**
   - 현재는 필드가 한 덩어리로 보여 “무엇이 핵심인지”가 약합니다.
   - 제안 레이아웃:
     - **필수**: 프로젝트 제목(필수), 목적(선택: 개인/팀/클라이언트)  
     - **콘텐츠 설정**: 장르, 분위기(또는 톤), 영상 길이(초/분)  
     - **AI 시작 옵션(선택)**: `AI 시나리오 생성으로 바로 시작` 토글

2. **드롭다운의 기본값/예시 제공**
   - 장르/분위기처럼 AI 결과에 큰 영향을 주는 필드는 기본값이 품질을 좌우합니다.
   - 제안:
     - placeholder `선택하세요` 대신 **추천 기본값**을 넣고,
     - 옆에 `추천` 배지로 신뢰를 줍니다.

3. **설명(Description)의 목적 명확화**
   - 사용자는 “무엇을 쓰면 좋은지” 모릅니다.
   - 라벨 아래 helper text:
     - `AI가 참고할 핵심 설정(캐릭터/배경/목표/톤)을 1~2문장으로 적어주세요.`

4. **제목 입력 규칙/검증**
   - 최소/최대 길이, 금칙문자 등 제한이 있다면 “입력 중” 실시간 안내가 좋습니다.

### 개선 포인트 (CTA/흐름)
- 지금 모달은 `프로젝트 생성`이 끝인데, 실제 사용자는 그 다음이 궁금합니다.
- 제안: 생성 버튼을 상황에 따라 2가지로 분기
  - `프로젝트 생성`(기본)
  - `생성하고 AI 시나리오 시작`(토글 ON일 때 primary)

### 모달 사용성 디테일
- ESC 닫기, 외부 클릭 닫기(단, 입력값이 있으면 확인), Enter 제출 규칙
- 입력값이 많은 경우: “작성 중 저장/임시 저장”은 향후 고려

## 2) 프로젝트 내부: Story 탭 & Scenes 빈 상태 (디자인_피드백.pdf 2p 하단)

### 현재 구조에서 사용자가 헷갈릴 수 있는 지점
- 상단 탭이 `Story / Scenes / Objects`로 되어 있는데,
  **Story에서 Scenes를 편집하는 구조**처럼 보이기도 합니다.
- “AI 시나리오 생성” 바(핑크 배너)가 강한데,
  현재는 배너가 “공지”인지 “버튼”인지 역할이 다소 혼재되어 보여요.

### 개선 포인트 (IA/내비게이션)
1. **‘Story’의 정의를 화면에서 설명**
   - 예: Story 탭 상단에 1줄:
     - `Story는 전체 시나리오(텍스트)와 씬 구조를 만드는 단계입니다.`
   - 또는 탭명을 더 직관적으로:
     - Story → `Script` / Scenes → `Shot List` 같은 방식(한글로는 ‘시나리오 / 씬 / 오브젝트’)

2. **좌측 사이드바(아이콘)와 상단 탭의 역할 분리**
   - 권장 원칙:
     - **사이드바** = 작업 공간(대시보드/프로젝트/캔버스/타임라인/프로필 등 “큰 이동”)
     - **상단 탭** = 프로젝트 내부의 “작은 구역 전환”
   - 지금은 둘 다 “구역 전환”처럼 보여 중복 인지가 생깁니다.

### 개선 포인트 (Scenes 빈 상태)
1. **Add Scene 버튼 중복 정리**
   - `+ Add Scene`(우측)과 `Add New Scene`(가운데)이 함께 있어요.
   - 제안:
     - 빈 상태에서는 가운데에만 큰 CTA  
     - 씬이 1개라도 생기면 우측 상단에 작은 `+ Add Scene`으로 이동

2. **빈 상태 가이드 문구 추가**
   - 예:
     - 제목: `아직 씬이 없어요`  
     - 설명: `AI 시나리오를 생성하거나, 직접 씬을 추가해 시작할 수 있어요.`
     - CTA 2개(Primary/Secondary):
       - Primary: `AI 시나리오 생성`
       - Secondary: `직접 씬 추가`

3. **‘AI 시나리오 생성’ 배너를 ‘단계형 CTA’로**
   - 배너 안에 Step 표시(1/4)를 넣고, 클릭 시 우측에서 패널/모달이 열리게 하면 “이 기능이 메인 경로”라는 인지가 생깁니다.
   - 피치덱에 있는 4-step UI를 실제 제품에서도 동일 패턴으로 가져가는 것을 추천합니다.

### 버튼/카피 제안
- 배너 버튼:
  - `AI 시나리오 생성 시작` (Primary)
  - 생성 완료 후: `시나리오 다시 생성`(Secondary) / `씬에 적용`(Primary)

## 3) 상단 Progress / Preview 영역 (디자인_피드백.pdf 2~3p 공통)

### 문제
- “Progress 0/1” 같은 표기가 보이는데, 사용자가 이것이 무엇을 뜻하는지 모르면 무의미합니다.

### 제안
- `Progress`를 “작업 단계 체크리스트”로 바꾸기:
  - 예) `스토리 작성` `씬 1개 생성` `영상 1개 생성` `Export`  
- Preview 버튼도 “무엇을 미리보는지”를 명확히:
  - `Scene Preview` vs `Full Preview` 등

### 체크리스트
- [ ] 빈 상태 CTA 중복 제거
- [ ] Story/Scenes/Objects 용어 정의/정렬
- [ ] AI 시나리오 생성 배너 → 단계형 CTA 전환
- [ ] Progress 의미를 사용자 언어로 재정의
