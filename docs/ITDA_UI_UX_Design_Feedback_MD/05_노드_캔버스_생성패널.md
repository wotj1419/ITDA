# 05. 노드 캔버스 · 생성 패널(마스터/그리드/씬/영상) 피드백

노드 캔버스는 이 서비스의 차별점이므로, **캔버스 사용성(조작/가독성) + 생성 UX(상태/버전/프리셋)** 두 축을 동시에 잡는 것이 핵심입니다.

---

## 1) 노드 캔버스 공통 (조작/가독성/학습)

### A. 캔버스 조작의 기본기 (필수)
작업형 툴에서 캔버스 UX의 기본 6종을 권장합니다.

1. **줌 인/아웃 + 현재 줌 퍼센트 표시**
2. **Fit to screen / Fit selection**
3. **미니맵(minimap)**: 노드가 많아지면 거의 필수
4. **그리드/스냅 토글**: 정렬 스트레스 감소
5. **정렬(Align) / 자동 레이아웃(오토정렬)**
6. **단축키 힌트( ? )**: `Space+Drag` 이동, `Cmd+Z` 되돌리기 등

> 현재도 좌측에 줌 컨트롤이 일부 보이지만, “Fit”과 “미니맵”이 빠지면 대형 프로젝트에서 급격히 불편해집니다.

### B. 선택(Selected) vs 활성(Active) vs 생성중(Generating) 상태 분리
캡처에서 핑크 강조가 강하게 들어가는데, 상태가 섞이면 인지가 어려워집니다.

- **Selected(선택됨)**: 테두리 1px + 약한 배경
- **Active(현재 편집 대상)**: 상단에 작은 칩(Active)
- **Generating(생성중)**: 진행바/스피너 + 잠금 아이콘(편집 제한)
- **Error(실패)**: 붉은 배지 + `재시도` CTA

이 4가지를 시각 언어로 분리하면 “AI가 어디까지 만들었는지”가 한눈에 보입니다.

### C. 노드 카드의 정보 구조
노드가 최소한 담아야 하는 정보:

- 썸네일(또는 placeholder)
- 이름(마스터 이미지 1 / 그리드 v2 / 샷 v1 등)
- 상태 배지(준비/생성중/완료/실패)
- 핵심 메타(해상도, 길이, 카메라 모션 등 1~2개만)
- 퀵 액션(재생성, 복제, 버전) → `…` 메뉴 추천

지금은 썸네일/이름 중심인데, 상태/버전이 강화되면 작업성이 올라갑니다.

## 2) 모드 전환(마스터/그리드/씬/영상) — ‘탭’ UX

### 문제 가능성
- 상단에 `마스터 → 그리드 → 씬 → 영상`이 있는데,
  사용자는 이것이 “단계”인지 “보기 모드”인지 헷갈릴 수 있습니다.

### 추천 구조
- **단계(Step)라면**: 완료/진행 표시 + “이전/다음”
- **보기(View)라면**: 탭 대신 “뷰 전환” 컨트롤처럼 보이게(아이콘+라벨)

추가로, 모드 전환 시:
- 현재 선택된 노드가 유지되는지
- 뷰가 바뀌면서 어떤 노드가 포커스되는지
규칙을 명확히 해야 합니다(예: 마스터→그리드 전환 시, 마스터 노드의 자식 그리드를 자동 선택).

## 3) 우측 생성 패널(공통) — 옵션 설계

### A. 옵션의 ‘층위’를 분리하세요 (기본/고급)
현재 패널은 많은 옵션이 한 번에 보여, 초보자에게 부담이 될 수 있습니다.

- 기본(항상 노출): 3~5개
  - 스타일/톤/시간대/길이/해상도 등 핵심
- 고급(접기): 나머지
  - seed, 카메라 파라미터, 디테일 보정, 네거티브 프롬프트 등

### B. “프롬프트 미리보기”는 거의 필수
사용자는 UI 옵션을 바꿨을 때 결과가 어떻게 달라지는지 알기 어렵습니다.
패널 하단에:

- `프롬프트 미리보기` (읽기 전용)
- `직접 수정(고급)` 토글

을 제공하면 숙련자/초보자 모두 만족도가 올라갑니다.

### C. 프리셋(저장/불러오기)
스타일/톤 조합은 반복 사용됩니다.
- `내 프리셋 저장` / `팀 프리셋` (협업 가치 강화)
- 프리셋에 썸네일과 짧은 이름(예: “따뜻한 필름룩”) 제공

## 4) 마스터 이미지 생성 패널 (디자인_피드백.pdf 4p)

### 관찰
- 스타일(라디오), 시간대, 공통 오브젝트(체크), 분위기 등 옵션이 있고,
  하단에 프롬프트 생성/이미지 생성 버튼이 보입니다.

### 개선 포인트
1. **“공통 오브젝트”는 토큰(Tag) UI가 더 적합**
   - 체크박스 리스트는 길어지면 스크롤이 늘어납니다.
   - 태그 입력 + 추천 칩:
     - 사용자가 직접 입력하고 엔터로 추가
     - 추천 태그를 클릭으로 추가

2. **프롬프트 생성 → 이미지 생성 2단계가 필요한 이유를 설명**
   - 사용자 입장에서는 버튼이 2개면 “뭘 먼저 누르지?”가 됩니다.
   - 제안:
     - 2단계가 필요하다면 버튼 레이블을 명확히:
       - `프롬프트 확인` → `이미지 생성`
     - 또는 하나로 합치고 고급에 “프롬프트 보기”

3. **옵션 간 의존 관계 처리**
   - 예: 스타일이 애니메이션이면, 일부 분위기/시간대 옵션이 비활성화될 수 있음
   - 비활성화 시 이유를 툴팁으로 설명

4. **생성 결과의 ‘버전’이 노드에 남도록**
   - 마스터 이미지 v1/v2/v3를 노드 내부에서 스택으로 관리(썸네일 리스트)
   - ‘핀(고정)’ 기능: 마음에 드는 결과를 잠그기(후속 생성에서 일관성 유지)

## 5) 그리드 생성(스토리보드) 패널 (itda-presentation-v2.pdf 18p)

### 개선 포인트
1. **그리드 크기 선택 UI**
   - 2x2, 2x3 같은 옵션은 “프리셋 버튼”으로 좋은데,
     선택 시 미리보기(레이아웃 썸네일)를 같이 보여주면 확신이 생깁니다.

2. **샷별 편집 진입**
   - 그리드가 생성되면 각 칸(샷)으로 바로 진입하는 CTA:
     - `이 샷으로 씬 생성` 또는 `샷 편집`
   - “그리드가 무엇을 위한 것인지”가 더 명확해집니다.

## 6) 씬 생성 패널 (itda-presentation-v2.pdf 19p)

### 개선 포인트
1. **샷 수(1~6 등) 선택은 ‘목적 기반’으로도 제안**
   - 숫자만 있으면 사용자는 고민합니다.
   - 예:
     - `짧게(3샷)` `표준(5샷)` `풍부하게(7샷)`
   - 내부적으로 숫자 매핑하면 됩니다.

2. **추가 지시사항 입력 UX**
   - placeholder 예시가 효과적:
     - `예) 카메라는 천천히 줌 인, 분위기는 고독하게…`
   - “너무 길게 쓰지 말기” 가이드도 중요(모델 성능)

3. **씬 생성 결과가 캔버스에서 어떻게 연결되는지 시각화**
   - 생성 버튼 누르면 새 노드가 아래에 “생성 중”으로 생성되고,
     연결선이 자동으로 연결되는 애니메이션이 있으면 학습이 매우 빠릅니다.

## 7) 영상 생성 패널 (itda-presentation-v2.pdf 20p)

### 개선 포인트
1. **모션 선택(아이콘 그리드) 레이블 강화**
   - 아이콘만 있으면 의미가 모호할 수 있어요.
   - hover/선택 시 라벨(예: `줌 인`, `패닝 좌→우`)이 반드시 필요

2. **해상도/비율/길이 같은 기술 옵션은 기본값을 강하게**
   - 초보자는 기술 옵션을 몰라도 결과를 얻어야 합니다.
   - 고급에서 바꾸게 하고, 기본은 “추천”으로 고정

3. **생성 시간 안내 + 백그라운드 작업**
   - 영상 생성은 오래 걸립니다.
   - UI에서:
     - `대기열에 추가됨` 상태
     - 알림(완료 시 토스트)
     - 실패 시 재시도
