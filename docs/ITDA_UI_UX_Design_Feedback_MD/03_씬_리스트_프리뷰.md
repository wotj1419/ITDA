# 03. 씬 리스트 · 씬 프리뷰 화면 피드백

_작성일: 2026-01-26_


## 1) Scenes 리스트 (Story 탭) — 씬이 1개 이상 있을 때 (디자인_피드백.pdf 3p 상단)

### 잘 된 점
- 리스트가 단순해 시작이 쉽고, `미리보기 / Edit` 액션이 각 씬에 붙어 있어 접근성이 좋습니다.
- SCENE 번호와 이름이 분리되어 있어 구조화가 가능합니다.

### 개선 포인트 (리스트 정보 밀도)
현재 행(Row) 안에 들어가면 좋은 최소 정보는 아래 5가지입니다.

1. **상태(Status)**
   - 예: `준비됨` / `생성 중` / `완료` / `실패` / `재생성 필요`
   - 지금도 작은 배지가 보이는데, “AI 생성”에서는 상태가 핵심이라 더 명확해야 합니다.
   - 색상만으로 구분하지 말고 **아이콘+텍스트** 병행(접근성)

2. **길이/샷 수 같은 요약 메타**
   - `0s`처럼 보이는데, 사용자에게 의미가 있으려면
     - `샷 6개 · 12초` 같은 형태가 더 직관적입니다.

3. **최근 수정/생성 시간**
   - 협업 시 특히 필요합니다.

4. **담당자/협업자(옵션)**
   - 실시간 협업을 강조한다면, 리스트에서도 “누가 작업 중인지”가 보여야 합니다.

5. **빠른 액션(… 메뉴)**
   - Edit 외에 필요한 액션:
     - `복제`, `순서 변경`, `삭제`, `내보내기`, `버전 보기`
   - 모든 버튼을 노출하면 복잡해지니 `…`로 넣어도 됩니다.

### 개선 포인트 (행 인터랙션)
- 행 전체 클릭 시 “씬 상세(프리뷰)”로 진입하고,
  오른쪽 버튼은 보조 액션으로 두면 학습이 쉬워집니다.
- Hover 시:
  - 썸네일 프리뷰(툴팁) 또는 상태/메타가 더 보이게 확장

### “Add New Scene” 버튼 위치
- 리스트 하단에 큰 버튼이 계속 남아 있으면 “콘텐츠보다 CTA가 커 보이는” 문제가 생길 수 있어요.
- 제안:
  - 씬이 생긴 뒤에는 상단의 `+ Add Scene`만 유지(하단 큰 버튼 제거)

## 2) Scene Preview (Scenes 탭) (디자인_피드백.pdf 3p 하단)

### 현재 관찰
- Scene Preview 영역이 넓은데, 실제로는 왼쪽에 씬 카드가 있고 우측에 큰 빈 영역이 있습니다.
- 사용자는 여기서 “무엇을 확인/편집할 수 있는지”를 즉시 알기 어렵습니다.

### 개선 방향: 3컬럼 정보 구조 추천
작업형 툴에서 “씬 프리뷰”는 아래 구조가 가장 안정적입니다.

1) **왼쪽: 씬 리스트(네비)**
- 현재처럼 리스트는 유지하되,
- 씬 이름 아래에 `샷 수·길이·상태`를 작은 텍스트로 제공

2) **가운데: 현재 씬의 핵심 콘텐츠**
- 옵션 A: **스크립트/내레이션/대사**(텍스트)
- 옵션 B: **샷 리스트(컷 단위)**  
  썸네일 + 카메라/모션 + 길이 + 생성 상태

3) **오른쪽: 생성/편집 패널**
- ‘노드 캔버스’가 별도 화면이라면, 여기서는 “가벼운 편집”만:
  - 톤/스타일 프리셋, 재생성, 참고 이미지 추가 등

### Full Timeline vs Scene Timeline 용어/버튼
- “Scene Timeline” 버튼이 있는데, 사용자는 이것이
  - 씬 전용 타임라인인지
  - 전체 타임라인의 특정 구간 점프인지
  헷갈릴 수 있습니다.
- 제안:
  - 버튼명을 명확히:
    - `씬 타임라인 보기` / `전체 타임라인 보기`
  - 클릭 시 이동 후, 상단 Breadcrumb로 현재 범위를 표시:
    - `프로젝트 > 씬 1 > 타임라인`

### 빈 프리뷰 상태의 가이드 (매우 중요)
- “확인된 씬이 없습니다” 같은 문구 대신, 다음 행동을 안내해야 합니다.
- 예시:
  - 제목: `아직 영상이 생성되지 않았어요`
  - 설명: `노드 캔버스에서 샷을 생성한 뒤, 타임라인에서 합칠 수 있어요.`
  - CTA:
    - Primary: `노드 캔버스로 이동`
    - Secondary: `AI로 샷 자동 생성`

### 체크리스트
- [ ] 씬 리스트 행에 상태/메타 강화
- [ ] 행 클릭 = 상세 진입, 버튼 = 보조 액션
- [ ] Scene Preview 3컬럼 구조로 “무엇을 하는 화면인지” 명확화
- [ ] Scene/Full Timeline 명칭 통일 + Breadcrumb
- [ ] 빈 프리뷰 상태에서 ‘다음 행동’ 제시
