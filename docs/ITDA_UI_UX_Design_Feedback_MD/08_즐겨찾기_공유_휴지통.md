# 08. 즐겨찾기 · 공유됨 · 휴지통 화면 피드백

_작성일: 2026-01-26_


## 1) Favorites (즐겨찾기) (디자인_피드백.pdf 7p 상단)

### 현재 관찰
- 즐겨찾기 프로젝트가 1개 있을 때, 리스트가 좌측에 작게 보이고 우측은 비어 있습니다.
- 썸네일에 “No Preview”가 떠 있어 콘텐츠 가치가 약하게 느껴집니다.

### 개선 포인트
1. **레이아웃을 ‘프로젝트 그리드’로 통일**
   - 대시보드(My Projects)와 동일한 카드 레이아웃을 재사용하면 학습 비용이 줄어듭니다.
   - 즐겨찾기는 “수집/보관” 성격이라 그리드가 더 어울립니다.

2. **썸네일 없는 프로젝트의 대체 썸네일**
   - No Preview는 부정적 인상을 줍니다.
   - 제안:
     - 첫 장면(마스터 이미지) 자동 캡처
     - 또는 장르/톤 기반의 컬러 커버 생성

3. **정렬/필터**
   - 즐겨찾기는 시간이 지날수록 쌓입니다.
   - 최소 정렬:
     - 최근 추가, 최근 수정, 제목순

4. **즐겨찾기 토글의 발견 가능성**
   - 사용자가 “어떻게 즐겨찾기 해제하지?”를 찾지 않게,
     카드에 ♥ 아이콘(상태 유지)을 명확히 제공

## 2) Shared with Me (디자인_피드백.pdf 7p 하단)

### 현재 관찰
- “This feature is coming soon!” 형태의 영어 empty state가 보입니다.

### 개선 포인트 (언어/톤)
1. **언어 통일**
   - 전체 제품이 한국어라면, 이 화면도 동일한 언어 톤으로 맞추는 게 좋습니다.
   - 예시:
     - 제목: `공유받은 프로젝트가 없어요`
     - 설명: `팀원이 공유한 프로젝트가 여기 표시됩니다.`
     - 보조: `곧 제공될 기능입니다.`(필요하다면)

2. **Coming soon 기능은 노출 방식 재검토**
   - “메뉴는 있는데 들어가면 Coming soon”은 신뢰를 깎을 수 있어요.
   - 대안:
     - 메뉴 자체를 숨기고, 초대/공유 기능이 열리면 노출
     - 또는 메뉴는 비활성(잠금) 상태로 두고 툴팁에 “곧 제공” 표시

3. **공유 UX의 기대 행동 안내**
   - 공유가 핵심이라면, empty state에서:
     - `프로젝트 공유 방법 보기`(가이드 링크)
     - `팀원 초대하기`(가능하다면)
   - “왜 비어있는지”가 아니라 “어떻게 채울지”를 알려야 합니다.

## 3) 휴지통 (디자인_피드백.pdf 8p)

### 잘 된 점
- `30일 후 영구 삭제` 정책 안내가 있어 사용자가 안심할 수 있습니다.

### 개선 포인트
1. **휴지통 리스트 상태 설계**
   - 항목이 있을 때 UX가 중요합니다.
   - 권장 구성:
     - 체크박스(다중 선택)
     - 프로젝트 이름/삭제일/남은 기간
     - 액션: `복원`(Primary), `즉시 삭제`(Danger)

2. **위험 행동(즉시 삭제) 보호**
   - 즉시 삭제는 2중 확인:
     - `정말 삭제할까요? 복구할 수 없습니다.`
     - 프로젝트명 입력 확인(고위험일 때)

3. **빈 상태 카피 개선**
   - 현재도 충분히 깔끔하지만, 브랜드 톤에 맞게 약간 친절하게:
     - `휴지통이 비어 있어요. 삭제된 프로젝트가 없습니다.`
