## 1) Full Timeline 화면 (디자인_피드백.pdf 5p 하단)

### 현재 관찰
- 상단에 큰 플레이어, 하단에 타임라인이 있고,
  타임라인 영역은 아직 “클립/트랙” 정보가 적어 보입니다.
- 빈 상태일 때 “무엇을 해야 하는지”가 약합니다.

### 개선 방향: 타임라인은 ‘편집’이 목적임을 시각적으로 드러내기
타임라인에서 사용자들이 기대하는 최소 기능(초기 MVP 기준)은 아래입니다.

#### A. 플레이헤드/스크러빙/줌
- 현재 시간 표시(00:00) + 드래그 가능한 플레이헤드
- 마우스 휠/핀치로 줌 인/아웃(또는 슬라이더)
- 스크러빙 시 프레임 썸네일(hover preview) 제공하면 편집 효율이 급상승

#### B. 트랙 개념 (최소 2~3개)
- Video 트랙(기본)
- Audio 트랙(선택)
- Caption/Subtitle 트랙(선택)
- 처음부터 다 넣기 어렵다면, “미래 확장”을 고려해 레이아웃만이라도 준비해두는 게 좋습니다.

#### C. 씬/샷 단위 네비게이션
- 위쪽 또는 왼쪽에 씬 목록을 두고, 클릭하면 해당 구간으로 점프
- 타임라인에 씬 마커(구간 색/라벨) 표시  
  → “스토리-노드-타임라인” 연결성이 강화됩니다.

### 빈 상태 UX(중요)
- 영상/클립이 0개일 때는:
  - 제목: `아직 합칠 영상이 없어요`
  - 설명: `노드 캔버스에서 영상(샷)을 생성하면 여기에서 순서를 편집할 수 있어요.`
  - CTA:
    - Primary: `노드 캔버스로 이동`
    - Secondary: `AI로 샷 생성`

## 2) Export / Preview CTA 배치

### 문제 가능성
- 상단에 Export/Preview가 있으면 좋지만,  
  “지금 Export 가능한 상태인지” 판단이 어렵습니다.

### 제안
- Export 버튼 옆에 상태:
  - `Export 가능` / `영상 생성 필요` / `렌더링 필요`
- 비활성(disabled)일 때는 이유 툴팁:
  - `최소 1개의 영상 클립이 필요합니다.`

## 3) 실시간 협업 패널 (itda-presentation-v2.pdf 21~22p)

### 현재 구조 장점
- 코멘트 패널이 오른쪽에 떠서, 작업 컨텍스트를 유지하며 피드백을 주고받을 수 있습니다.
- “어떤 화면에서도 연결 유지” 메시지와 잘 맞습니다.

### 개선 포인트: 코멘트는 ‘앵커(Anchor)’가 핵심
협업 코멘트가 강력해지려면 반드시 아래가 필요합니다.

1. **코멘트가 어디에 달렸는지 명확히**
   - 캔버스: 노드/샷/그리드에 앵커(핀) 표시  
   - 타임라인: 타임스탬프에 마커 표시  
   - 클릭하면 해당 위치로 자동 이동 + 하이라이트

2. **해결(Resolved) / 미해결(Unresolved) 상태**
   - 협업 도구의 기본.  
   - 해결된 코멘트는 접히거나 필터링 가능해야 합니다.

3. **멘션(@) + 알림**
   - `@민준`처럼 특정 사용자에게 액션을 요청할 수 있어야 “협업”이 됩니다.
   - 완료 알림(토스트/뱃지)과 함께, 프로젝트 내 Notification Center(최소 MVP에선 토스트+뱃지로도 OK)

4. **패널 도킹/접기**
   - 화면이 좁거나 타임라인 편집에 집중할 때 패널이 방해가 될 수 있어요.
   - `접기(>)` + 아이콘만 남기기, 또는 “우측 도킹” 방식 추천

### UX 안전장치
- 작성 중인 댓글이 있을 때 화면 이동하면:
  - `작성 중인 메시지가 있어요. 저장하지 않고 이동할까요?`

## 4) 협업 존재감(Presence) UI

실시간 협업의 설득력을 높이는 작은 요소:
- 현재 접속자 아바타(상단)
- 다른 사용자의 커서/선택 노드 하이라이트(옅게)
- 누가 무엇을 편집 중인지(노드/씬 옆에 작은 라벨)
