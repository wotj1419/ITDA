# ITDA (AI Movie Studio) UI/UX 디자인 종합 진단 & 우선순위

_작성일: 2026-01-26_


## 자료 범위

- **UI 캡처 기반**: `디자인_피드백.pdf`의 각 화면(로그인/대시보드/프로젝트/노드 캔버스/타임라인/프로필/라이브러리/휴지통)을 기준으로 작성했습니다.
- **플로우 보강**: `itda-presentation-v2.pdf`에 포함된 **AI 시나리오 생성(4-step)** 및 **노드 캔버스(마스터/그리드/씬/영상)**, **실시간 협업** 화면을 추가로 반영했습니다.

> 캡처 해상도 특성상 일부 텍스트/아이콘은 정확히 판독되지 않는 부분이 있어, **레이아웃/인터랙션/정보구조 중심**으로 피드백했습니다.

## 지금 UI의 강점 (계속 가져가면 좋은 것)

1. **미니멀한 톤 & 넉넉한 여백**  
   작업형 툴에서 “복잡한 AI 옵션”을 담아야 하는데, 기본 베이스가 깔끔해서 확장 여지가 큽니다.
2. **일관된 포인트 컬러(핑크)로 액션 강조**  
   Primary CTA(생성/시작/Preview 등)가 눈에 띄는 편입니다.
3. **노드 기반 구조 자체가 가치 제안과 맞음**  
   “맥락 유지/실험 가능/재사용” 컨셉(피치덱)과 UI 메타포가 잘 맞습니다.

## 가장 큰 리스크 3가지 (사용자가 흔히 막히는 지점)

### 1) “다음에 뭘 해야 하지?”가 화면에서 바로 안 보임
- 빈 상태에서 **가이드/추천 액션/샘플**이 부족해 첫 성공 경험(첫 씬 생성 → 첫 영상 생성 → Export)이 늦어질 가능성이 큼.
- 특히 **Story/Scenes/Objects / 노드 캔버스 / 타임라인** 간 관계가 “초심자”에게는 낯설 수 있습니다.

### 2) 정보 구조(IA)와 내비게이션의 역할 분리가 흐림
- 좌측 사이드바(아이콘) + 상단 탭(Story/Scenes/Objects) + 상단 우측 버튼(Preview/Export) 등 **상호 중복**이 보입니다.
- “현재 위치”와 “작업 범위(프로젝트/씬/샷/영상)”가 분명하지 않으면, 생성 파이프라인 UX가 급격히 어려워집니다.

### 3) 생성/편집/협업 상태가 시각적으로 명확하지 않음
- AI 생성은 “진행 중 / 대기 / 실패 / 완료 / 재생성 / 버전” 상태가 필수인데,
  노드 카드/리스트/타임라인에서 상태 언어가 아직 충분히 드러나지 않습니다.

## 우선순위 로드맵 (Quick Win → Mid → Long)

### Quick Win (1~3일 내 효율 좋은 개선)
- **빈 상태(Empty State) 6종** 정비:  
  프로젝트 없음 / 씬 없음 / 미리보기 없음 / 공유 없음 / 즐겨찾기 없음 / 휴지통 비어 있음  
  → “단 1개의 CTA + 2줄 가이드 + 샘플/템플릿” 패턴으로 통일
- **용어 통일(한국어/영어 혼용 제거)**:  
  예) Scene Timeline / Full Timeline / Preview / Export / Shared with Me 등
- **Primary CTA 체계화**:  
  화면마다 “1개만” 가장 중요한 버튼이 돋보이게(나머지는 Secondary/Link)

### Mid (1~2주)
- **IA 재정의 & 내비 구조 정리**  
  프로젝트 홈(개요) / 스토리(텍스트) / 씬(샷/에셋) / 캔버스(생성/버전) / 타임라인(편집/조합) / Export
- **상태 시스템 설계(디자인 시스템 레벨)**  
  생성중(스피너) / 완료(체크) / 실패(에러) / 재시도 / 잠금(락) / 버전(1,2,3)
- **AI 설정 패널 정보 설계**  
  (기본/고급) 토글, 프리셋, “내가 바꾼 옵션만” 표시, 프롬프트 미리보기

### Long (1달+)
- **협업 UX 고도화**  
  코멘트(노드/타임스탬프 앵커) + 멘션 + 해결/보류 + 알림 + 권한
- **온보딩/튜토리얼(First Run Experience) 구축**  
  3분 안에 “첫 결과물 Export”까지 가이드하는 guided flow
- **프로젝트 템플릿/갤러리**  
  베스트 프랙티스를 UI에 내장(예: “홍보 영상 15초”, “뮤직비디오 30초”)

## 공통 디자인 가이드 (이 프로젝트에 특히 중요한 7가지)

1. **초보자에게는 ‘절차’(Step), 숙련자에게는 ‘툴’(Tool)**
2. **생성형 UX는 ‘상태(Progress) + 취소/재시도 + 버전’이 3종 세트**
3. **노드 캔버스는 “캔버스 조작(줌/미니맵/정렬)”이 기본 사용성**
4. **타임라인은 “스크러빙/줌/클립 단위”가 최소 요건**
5. **AI 옵션은 “기본값이 완성도를 결정” (Default is product)**
6. **언어/용어/단위(초/프레임/샷/씬) 통일**
7. **접근성(포커스/대비/키보드) — 작업형 툴은 특히 중요**
