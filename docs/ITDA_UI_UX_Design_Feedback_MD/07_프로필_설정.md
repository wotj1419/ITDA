# 07. 프로필 · 프로필 편집 화면 피드백

_작성일: 2026-01-26_


## 1) 프로필(공개 포트폴리오) 화면 (디자인_피드백.pdf 6p 상단)

### 잘 된 점
- 프로필 헤더 카드(아바타/이름/직함/소개/링크)가 깔끔하고,
  통계(Projects/Followers/Following)도 한눈에 보입니다.
- Public Projects 카드 레이아웃이 안정적이며 썸네일 중심이라 콘텐츠가 돋보입니다.

### 개선 포인트 (정보 구조 & 목적 명확화)
1. **이 화면이 ‘내 작업 공간’인지 ‘공개 포트폴리오’인지 구분**
   - 지금은 “공개 프로젝트”가 있어서 포트폴리오 성격이 강한데,
     사용자는 혼란스러울 수 있습니다.
   - 제안:
     - 상단에 토글: `내 프로필(공개)` / `내 계정(설정)`
     - 또는 메뉴 분리: Profile vs Settings

2. **프로필 CTA 강화**
   - “프로필 수정”은 있으나, 프로필 화면에서 사용자가 자주 하는 행동:
     - `프로필 공유`(링크 복사)
     - `새 프로젝트 만들기`
     - `포트폴리오로 내보내기`(선택)
   - CTA 우선순위 설계 권장

3. **통계의 의미 보강**
   - Projects/Followers/Following이 있다면
     “플랫폼의 소셜 기능”을 강하게 암시합니다.
   - 실제 MVP에 소셜이 약하다면, 통계를 줄이거나
     대체 지표(예: `완성한 영상`, `총 재생 시간`)로 바꾸는 것도 전략입니다.

### 프로젝트 카드 개선 제안
- 카드 하단 메타:
  - 길이(초), 장르/톤 태그, 생성 일자, 협업자 수
- Hover 시:
  - `Play` / `Open Project` / `Share` 퀵 액션

## 2) Edit Profile 화면 (디자인_피드백.pdf 6p 하단)

### 잘 된 점
- 폼이 단정하고, 섹션이 Profile / Contact / Location 으로 나뉘어 있어 이해가 쉽습니다.
- Bio 글자 수 카운트가 있는 점은 아주 좋습니다.

### 개선 포인트 (폼 UX)
1. **저장/취소 패턴 명확화**
   - 현재 스크린샷에서는 저장 버튼이 명확히 보이지 않습니다(있더라도 강조가 약할 수 있어요).
   - 추천:
     - 상단 오른쪽 `저장`(Primary) + `취소`(Secondary)
     - 또는 하단 고정(Fixed) 저장 바

2. **변경사항 감지(Unsaved changes)**
   - 사용자가 뒤로 가기/이동할 때
     - `저장하지 않은 변경사항이 있어요` 확인 모달

3. **프로필 사진 업로드 UX**
   - 권장:
     - 크롭/리사이즈
     - 허용 포맷/용량 표시
     - 업로드 중 진행 표시
   - 실패 시 재시도 버튼

4. **공개 범위(Privacy) 옵션**
   - 이메일/웹사이트/위치 등은 공개 민감도가 다릅니다.
   - 토글 추천:
     - `이메일 공개` / `위치 공개`
   - 특히 “협업”이 있는 서비스라면 개인정보 설정은 신뢰에 직결됩니다.

5. **URL 필드 검증**
   - Website는 프로토콜 자동 보정(`https://` 자동 추가)
   - 잘못된 URL 입력 시 즉시 안내

### 마이크로카피 제안
- Bio helper:
  - `어떤 영상을 만들고 싶은지, 주로 사용하는 스타일을 적어주세요.`
