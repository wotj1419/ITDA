# 씬 에디터 프롬프트 UX 정리 (2026-01-30)

이 문서는 **씬 에디터 패널들**에서 프롬프트 UX를 어떻게 구성했는지 정리한 것이다.  
나중에 이 문서만 읽어도 동작과 의도를 이해할 수 있도록 흐름/상태/버튼 의미까지 포함한다.

## 범위
- 대상 컴포넌트:
  - `itda-frontend/src/components/scene-editor/panels/MasterImagePanel.vue`
  - `itda-frontend/src/components/scene-editor/panels/ShotPanel.vue`
  - `itda-frontend/src/components/scene-editor/panels/StoryboardGridPanel.vue`
  - `itda-frontend/src/components/scene-editor/panels/VideoPanel.vue`
- 적용 범위: **마스터 / 샷 / 그리드 / 비디오 패널**

## 용어
- **서술 프롬프트(EN/KO)**: 사용자가 직접 수정하는 장면 설명용 프롬프트.
- **최종 프롬프트(영어)**: 실제 생성에 사용되는 최종 영어 문장.
- **AI로 다듬기**: 서술 프롬프트(EN)와 KO를 AI가 생성/보정.
- **승인**: 이 프롬프트로 생성해도 된다는 상태 확정.

## 서술 프롬프트 (EN/KO)
### 토글 구조
- EN/KO 세그먼트 토글로 한 번에 하나만 표시.
- EN: 기본 소스(편집 가능)
- KO: 번역본(편집 가능)

### 자동 채우기
- **마스터 패널에서만** 씬 설명(description)을 EN에 **최초 1회 자동 채움**.
- 이후 씬 설명이 바뀌어도 자동 덮어쓰기 하지 않음.

### KO 편집 강제 흐름 (A+B 적용)
KO 수정은 반드시 EN에 반영되도록 강제:
1. **KO 수정 시** `isKoOutOfSync = true`
2. **승인/이미지 생성 비활성화**
3. **KO 탭 → EN 탭 전환 시 자동 EN 반영**
4. KO 탭에 있는 **“영어로 반영” 버튼**은  
   - KO 수정 전: 비활성(회색)  
   - KO 수정 후: 활성(핑크 강조)

### 버튼
| 위치 | 버튼 | 동작 |
| --- | --- | --- |
| EN 탭 | 없음 | (자동 번역 버튼 제거됨) |
| KO 탭 | **영어로 반영** | KO → EN 재작성 (AI) |

> 자동 번역(EN→KO)은 제거됨.  
> KO를 업데이트하려면 **AI로 다듬기**를 다시 사용하거나 직접 수정해야 함.

## 최종 프롬프트 (영어)
### 자동 갱신
서술 프롬프트 또는 스타일/시간/분위기/오브젝트가 변경되면  
최종 프롬프트를 **자동으로 재계산**한다. (600ms 디바운스)
- 단, 사용자가 최종 프롬프트를 직접 편집 중이면 자동 갱신 중단.

### 직접 편집 토글 (단일 버튼)
- 기본: 읽기 전용
- 버튼 클릭 시: **편집 모드 진입**
  - 문구: “영문 직접 편집” → “편집 완료” 토글
- 편집 완료 후에도 **사용자 입력 유지(오버라이드 유지)**

---

## “한국어로 편집” 버튼
최종 프롬프트 영역에 배치된 **빠른 이동 버튼**:
- 클릭 시
  1. KO 탭으로 전환
  2. 서술 프롬프트 영역으로 **부드럽게 스크롤**
  3. KO textarea 포커스
  4. 서술 프롬프트 섹션 **하이라이트 애니메이션**

이 버튼으로 사용자는 “최종 프롬프트를 고치고 싶다 → 한국어 편집 위치로 이동” 흐름을 바로 이해할 수 있다.

---

## 주요 상태/제약 요약
### KO 동기화 상태
- `isKoOutOfSync = true` 상태이면:
  - “영어로 반영” 버튼 활성화
  - 승인/이미지 생성 비활성화
  - 안내 문구 노출: **“영어 반영이 필요합니다.”**

### 자동 갱신 조건
자동 프롬프트 갱신은 아래 조건에서만 동작:
- 서술 프롬프트(EN) 변경
- 스타일/시간/분위기/오브젝트 변경
- **최종 프롬프트 직접 편집 중이 아닐 때**

---

## 버튼 의미 요약
| 버튼 | 의미 |
| --- | --- |
| AI로 다듬기 | EN+KO 생성/보정 |
| 영어로 반영 | KO → EN 재작성 |
| 영문 직접 편집 / 편집 완료 | 최종 프롬프트 직접 편집 토글 |
| 한국어로 편집 | KO 편집 위치로 스크롤 + 포커스 |
| 승인 | 현재 프롬프트 확정 |
