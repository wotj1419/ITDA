# 10) Video Studio 방향 + Studio Mode(다크 토글) (16:9 기준)

요청 의도: “영화 제작(Story)” 느낌도 좋지만, 더 강하게 **AI 영상 제작 스튜디오(편집툴/NLE + 생성툴)** 인상을 주고 싶음.
또한 어두운 무드는 전면 적용보다 **Studio Mode 토글(다크모드 전환)** 이 더 적합.

## 결론(권장 방향)

- 기본 테마: **라이트(밝은 스튜디오)** 유지
- 대상 화면: `씬 편집`, `타임라인`은 상단바 우측에 **Studio Mode 토글** 제공
- 토글 목적: “몰입/프로툴” 감성 + 데모 임팩트(전환 연출 포함)
- 기준 출력: **16:9(가로)** 중심 UI 언어(타임코드/프레임/트랙/모니터)

## Default vs Alternatives (문서 운영 원칙)

- Default(권장안): 라이트 기반 레이아웃을 “스튜디오 툴”로 보이게 만드는 패널 구조(모니터/큐/인스펙터)를 **디폴트로 고정**
- Alternatives(옵션): Studio Mode/Atmosphere/패널 접기 같은 선택지를 토글로 제공

## 1) “라이트인데도 툴처럼 보이게” 만드는 5가지

1) **Preview Monitor를 항상 주인공으로**
   - 제작 화면에는 “모니터(16:9 플레이어)”가 어디서든 보이게(타임라인 상단 고정 권장)
2) **타임코드/해상도/길이 메타를 전면에**
   - `00:12 / 01:00`, `16:9`, `1080p`, `24fps` 같은 툴 언어는 라이트에서도 바로 “스튜디오”로 보이게 함
3) **패널 레이아웃(모니터-트랙-큐)**
   - Story 중심 탭보다, 제작 화면에서는 `Preview` / `Timeline` / `Render Queue` 2~3영역 고정
4) **상태=색만이 아니라 형태**
   - PENDING/RUNNING/SUCCEEDED/FAILED는 배지 + 아이콘 + (가능하면) 미세 모션
5) **라운드/그림자는 절제**
   - 큰 둥근 카드 남발은 “SaaS”로 보임
   - 패널/스트립/칩 중심(라운드는 작게 통일)

## 2) Studio Mode(다크 토글) 설계

### 어디에 적용할까?

- 1순위: `씬 편집`, `타임라인`
- 2순위(옵션): `프로젝트 상세 Scenes 탭` (프리뷰 중심일 때만)
- 랜딩/로그인/대시보드까지 다크로 바꾸는 건 “친근함”을 떨어뜨릴 수 있어 비추천

### 토글 UX

- 위치: 상단바 우측(Export/Preview 근처)
- 라벨: “Studio Mode”
- 상태 표현:
  - OFF: 라이트
  - ON: 다크(모니터/타임라인 영역이 더 선명하게)

### 전환 모션(과하면 싼티)

- 150~200ms 크로스페이드 + 배경만 부드럽게 전환
- `prefers-reduced-motion`이면 즉시 전환

## 3) 토큰(디자인 시스템) 관점

라이트/다크는 “색만 바꾸는 것”이 아니라, 툴의 초점이 달라져야 함.

- Light(기본)
  - 배경: 따뜻한 오프화이트
  - 패널: 한 톤 어두운 회색
  - 강조(브랜드): 핑크(Primary 1곳 집중)
- Dark(Studio Mode)
  - 배경: 잉크/차콜
  - 패널: 깊은 회색 + 얕은 테두리
  - 강조: 핑크는 “네온 하이라이트”처럼(글로우는 선택 상태에서만)

추가 규칙(둘 다 공통):

- 실패/경고 색은 핑크와 혼동되지 않게 분리(레드 톤 고정)
- 진행/성공은 블루/민트 계열로(핑크와 대비)

## 4) 화면별 적용 포인트(짧게)

- 프로젝트 상세(Scenes)
  - 프리뷰 카드(16:9) + 씬 스트립 + “Render Queue 요약(0/3)”으로 영상 제작 감성 강화
- 씬 편집
  - 캔버스는 유지하되, 상단/우측에 “모니터/큐”가 같이 살아야 “AI 영상 제작” 느낌이 남
  - Studio Mode ON이면 캔버스보다 모니터/노드 상태가 더 또렷하게
- 타임라인
  - 기본 스케일을 0~60s(또는 총 길이)로
  - Studio Mode ON이면 눈금/클립 대비를 올려 “편집툴” 질감 강화
