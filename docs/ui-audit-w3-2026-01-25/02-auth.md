# 02) 로그인/회원가입 (`/auth`)

스크린샷(1440x900): `screenshots-1440x900/01-auth-login.png`

## 현재 관찰

- 깔끔하고 빠르게 이해되는 카드형 로그인.
- 하지만 “영화 제작 스튜디오”의 세계관/무드가 거의 드러나지 않음.
- 실패/로딩 상태가 “폼 아래 에러 텍스트” 수준이면 데모에서 긴장감이 떨어질 수 있음.

## 뷰포트(데스크톱)로 보니 더 뚜렷한 점 (1440x900 기준)

- 중앙 폼이 “작게 떠 있는” 느낌이라, 화면이 넓을수록 허전함이 커짐.
- 이 경우 “좌측 비주얼 + 우측 폼”의 2컬럼이 가장 효과적으로 ‘스튜디오 입장’ 인상을 줌.

## 디자인 개선 제안

### 0) 언어 통일(한국어 올인)

- 로그인 화면은 “제품 첫 인상”이라, 영문 카피/라벨이 섞이면 완성도가 확 떨어짐.
- 추천: 제목/서브카피/placeholder/버튼/토스트 메시지를 **전부 한국어**로 정리(필요하면 용어만 괄호로 보조).

### 1) 레이아웃을 “스튜디오 입장”처럼

- 좌측(또는 상단)에 “짧은 시네마틱 비주얼”을 고정:
  - 그라데이션 + 필름 프레임 + 프로젝트 타임라인 실루엣
  - 작은 문구로 “Script → Storyboard → Video → Timeline”을 표기(제품 이해 도움)
- 폼은 지금처럼 단순 유지하되, 카드의 “핑크 테두리”만으로는 약함 → **얕은 글로우 + 미세한 그림자**로 떠 보이게

#### 데스크톱 레이아웃(>=1280px) 구체안

- Left: 16:9 모니터 프레임(더미 영상/이미지) + “Script→Storyboard→Video→Timeline” 미니 스텝
- Right: 로그인 폼(현재 카드 유지)
- 장점: 라이트 모드에서도 “영상 제작툴” 맥락이 즉시 전달됨

#### 모드별 톤

- Bright Studio(라이트, 기본): 현재처럼 밝게 두되 “툴” 메타(예: `16:9`, `00:00 / 01:00`)를 아주 작게 넣어 제작툴 인상을 줌
- Studio Mode(다크, 선택): 로그인은 굳이 다크로 안 가도 되지만, 사용자가 Studio Mode를 켠 상태로 진입할 수 있으니
  - 배경만 어둡게 전환되고 폼 카드 대비를 올리는 수준으로만 대응(과도한 네온은 제작 화면에서)

### 2) 폼 디테일(신뢰감)

- 입력 포커스: 테두리 색 변화만이 아니라 **라벨이 위로 살짝 이동 + 하이라이트 바**(전형적인 floating label)
- 비밀번호 토글: 아이콘만 있으면 의도가 약함 → “표시/숨김” 툴팁 또는 시각적 상태 차이
- “로그인 상태 유지”는 체크박스 크기/클릭 영역 확장(손/마우스 실수 감소)

### 3) 에러/성공 상태 연출

- 로그인 성공 토스트가 이미 있음 → 이걸 “입장 성공”처럼 조금 더 드라마틱하게:
  - 토스트 배경을 단색이 아니라 **빛나는 배지**(짧은 400ms)
  - 성공 후 대시보드로 넘어가기 전 0.2~0.3초 “전환 프레임”을 둬서 체감 품질 향상
- 실패 시:
  - 입력 필드 아래만 붉게 표시하기보다, 카드 상단에 **요약 메시지 + 해결 가이드(예: 비번 재확인)** 제공

## 전환/모션 제안

### 탭 전환(로그인 ↔ 회원가입)

- 탭 하단 인디케이터를 “왼쪽→오른쪽 슬라이드”
- 콘텐츠는 동시에 크로스페이드(150ms) + 높이 변화는 `transition: height` 대신 `scaleY`/`clip-path`로 튐 최소화

### 로그인 버튼

- 클릭 시:
  - 버튼 내부 아이콘이 **스피너로 자연스럽게 변환**(아이콘 morph가 어렵다면 교체 + 페이드)
  - 네트워크 대기 중에는 버튼이 약간 어두워지고 “그라데이션이 흐르는” 느낌(로딩이 지루하지 않게)
