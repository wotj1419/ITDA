# 01) 랜딩 (`/`)

스크린샷(1440x900): `screenshots-1440x900/00-landing.png`

## 현재 관찰

- 히어로(제목/서브카피/CTA) 구조는 명확하고 “데모 보기” CTA도 좋음.
- 다만 전체 톤이 “밝은 SaaS” 쪽으로 기울어, PRD가 말하는 “영화 제작 스튜디오/툴” 느낌이 약함.
- 해커톤 데모 기준으로는 **한국어 올인**이 더 설득력 있음(현재 EN/KO 혼용은 신뢰도 저하 요인).

## 뷰포트(데스크톱)로 보니 더 뚜렷한 점 (1440x900 기준)

- 히어로가 가운데 “큰 여백” 위에 놓여 있어 고급스럽긴 한데, “툴”보다는 “마케팅 페이지”로 더 강하게 읽힘.
- 영상 제작 스튜디오 감성을 원하면, 히어로 안에 **16:9 모니터/타임코드 메타**를 더 과감히 끼워 넣는 게 효과적.

## 디자인 개선 제안 (임팩트 중심)

### 1) “Video Studio” 분위기 강화 (모드별)

- Bright Studio(라이트, 기본)
  - 핑크 그라데이션은 유지하되, “툴” 인상을 주는 **모니터 프레임/타임코드(16:9)** 메타를 히어로 비주얼에 얹기
  - “데모 보기”는 실제로는 영상이 없어도, **데모 릴(Showreel) 카드**처럼 보이게(타임코드/해상도/길이 배지)
- Studio Mode(다크, 선택)
  - “짙은 네이비/차콜 + 핑크/코랄 네온 하이라이트” 같은 무드는 **Studio Mode에서만** 제공(테마 토글)
  - 필름 그레인/비네팅/스캔라인 같은 “분위기 효과”도 **옵션 토글(Atmosphere: Clean ↔ Filmic)** 로 분리

### 2) 메시지/카피 정리(언어 일관성)

- 데모 시연이 목적이면 랜딩은 “한 줄 가치”와 “바로 시작”만 남기고 텍스트 밀도를 줄이는 편이 효과적
  - 예: Hero 카피를 한국어로 통일 + 2줄 이내
  - “v2.7 Rose - Now Available” 같은 배지는 해커톤 데모에서는 오히려 산만 → “데모 전용 배지”로 교체(예: “Hackathon Demo Build”)

### 3) CTA를 1개로 수렴 + 2차 액션은 ‘가볍게’

- Primary CTA: “무료로 시작하기” (명확)
- Secondary CTA: “데모 보기”는 버튼이 아니라 **텍스트 링크 + 재생 아이콘** 정도로 톤 다운(시선 집중)

## 전환/모션 제안

### 랜딩 → 로그인(`/auth`)

- CTA 클릭 시:
  - 버튼이 **살짝 눌리며(scale 0.98)**, 라우트 전환은 **페이드 + 위로 12px** 이동
  - 헤더/CTA는 `View Transition API`로 **공유 요소(shared element)** 느낌(Chrome 기준 데모 임팩트 큼)

### 히어로 비주얼(데모 카드)

- 페이지 로드 시:
  - 포스터 영역은 **100~150ms 지연 후** “카메라 포커스 맞추는 느낌”으로 약한 블러 → 선명해짐
  - 플레이 버튼은 호버 시 **링(원형 파장)** 애니메이션(2회만, 무한 반복 금지)
