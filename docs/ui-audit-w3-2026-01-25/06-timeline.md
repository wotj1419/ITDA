# 06) 타임라인 (`/projects/:id/timeline`)

스크린샷:

- 빈 타임라인(1440x900): `screenshots-1440x900/10-timeline-empty.png`

## 현재 관찰

- 미리보기(플레이어) + 트랙 구조 자체는 PRD와 일치.
- 하지만 현재 빈 상태에서:
  - 상단 시간축이 과하게 길게 보여(0~10분까지) 데모에서 “복잡하고 어려운 툴”로 보일 수 있음
  - “확정된 클립 없음”이 단순 텍스트/아이콘 중심이라 감성/임팩트가 약함

## 뷰포트(데스크톱)로 보니 더 뚜렷한 점 (1440x900 기준)

- 트랙/프리뷰가 가운데 떠 있고 주변 여백이 커서, “편집툴 패널”보다 “큰 웹페이지 섹션”처럼 보임.
- 즉, 좁은 화면에서의 문제(답답함)보다 넓은 화면에서 **패널화/밀도 부족**이 더 큼.

## 디자인 개선 제안

### 0) 16:9 기준 “편집툴” 레이아웃으로 보이게

- 프리뷰는 16:9 고정(가능하면 플레이어 크기를 더 키우고, 타임코드/해상도 메타를 함께 노출)
- 상단바에 Studio Mode 토글(다크 전환)을 두면 “스튜디오 툴” 인상이 강화됨

#### 모드별 톤

- Bright Studio(라이트, 기본): 라이트 톤에서도 “트랙/눈금/클립” 대비를 충분히 확보(연한 핑크 점선만으로는 툴 감성이 약함)
- Studio Mode(다크, 선택): 눈금/클립 대비를 크게 올려 “NLE” 감성 강화(특히 타임코드/눈금의 선명도)

### 1) 타임라인은 기본 60초(또는 총 길이 기반)로 스케일링

- PRD 기본 목표가 “1분 내외 단편”에 가까움 → 기본 줌 스케일을 0~60s에 맞추면 직관성이 크게 올라감.
- 현재처럼 10분까지 눈금이 보이면 “전문 편집툴” 느낌은 나지만, 현재 기능 범위(P0)에서는 오히려 부담.

### 2) 빈 상태를 “확정 클립을 넣으세요”로 안내

- Empty state를 단순 안내 문구가 아니라:
  - “씬 편집으로 이동” CTA
  - “확정 클립이 생기면 여기서 순서 편집/병합” 짧은 설명
  - 작은 예시(더미 클립 2개가 드래그되는 애니메이션)까지 넣으면 데모 임팩트가 큼

### 3) 상단 액션(병합/다운로드) 위계 정리

- `영상 병합하기`가 비활성일 때도 큰 버튼으로 보이면 “왜 안 되지?”를 유발.
- 추천:
  - 비활성 상태에서는 버튼을 작게 접고(secondary),
  - 대신 “클립 0개 / 총 길이 0:00” 요약을 강조(왜 비활성인지 즉시 이해)

## 전환/모션 제안

### 씬 편집 → 타임라인

- “확정 클립”이 있다면:
  - 하단 미니 타임라인(씬 편집)에서 상단 타임라인으로 “확대”되는 공유 요소 전환이 매우 효과적
- Empty라면:
  - 타임라인 진입 시 “빈 트랙”이 오른쪽에서 살짝 등장하며(200ms) 안내 카드가 120ms 뒤에 따라 등장

### 드래그/드롭(클립)

- 드래그 시:
  - 클립이 살짝 떠오르며(그림자 증가), 드롭 위치에 “삽입 라인”이 나타나야 사용자가 확신을 가짐
  - 드롭 후:
  - 120ms 스냅(snap) 애니메이션(스프링 계열 이징)으로 “툴이 잘 만들었다” 느낌 강화

## 데스크톱 레이아웃 제안(>=1280px)

### Default (권장안): NLE 2-Panel + Inspector

- Left (Main): 타임라인 트랙 영역(가로 폭을 최대한 사용)
  - 트랙은 중앙 “짧은 박스”가 아니라, 화면 폭을 적극적으로 채워야 툴처럼 보임
- Right (Sticky Inspector): **항상 노출**
  - 선택 클립 정보(길이/상태/프롬프트/확정 여부)
  - Render/Merge Queue(진행 상태)

### Default (상단): Preview Monitor (16:9)

- 타임라인 상단에는 16:9 모니터를 유지
  - Empty 상태에서도 “모니터 프레임 + 타임코드 + 해상도 배지”로 스튜디오 인상 유지

### Alternatives (옵션/토글)

- `Inspector Collapse`: 오른쪽 패널 접기(발표 화면/좁은 데스크톱 대응)
- `Studio Mode`: 다크 전환(타임코드/눈금 대비 강화)
- `Atmosphere`: Filmic 효과 On/Off
- 하단 툴바(옵션): 줌 슬라이더/스냅 토글/그리드 단위(0.5s/1s) 같은 “툴 컨트롤”
