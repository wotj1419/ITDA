# 09) 전반적 디자인 개선(비주얼 시스템 제안)

화면별 개선과 별개로, “해커톤 데모에서 한 번에 고급스럽게 보이는” 공통 시스템을 먼저 잡는 게 효과가 큽니다.

## 1) 컬러 방향 (라이트 기본 + Studio Mode 다크)

요구사항: 기본은 밝게 유지하되, 제작 화면에서 “프로툴 무드”가 필요하면 **Studio Mode 토글**로 다크 전환.

- Light(기본, 전체 공통)
  - **Base(배경)**: 따뜻한 오프화이트/아주 옅은 핑크 그레이
  - **Surface(패널)**: 한 톤 어두운 회색(패널 분리감)
  - **Accent(강조)**: 핑크는 Primary CTA 1곳에 집중
- Dark(Studio Mode, 제작 화면 중심)
  - **Base(배경)**: 잉크/차콜
  - **Surface(패널)**: 깊은 회색 + 얕은 보더
  - **Accent(강조)**: 핑크는 “네온 하이라이트”로(선택 상태에서만 글로우)

추천 규칙(라이트/다크 공통):

- Primary CTA는 항상 1개만 “핑크 채움”
- Secondary는 “아웃라인/유리 버튼”
- Danger/Fail은 붉은색을 쓰되, 핑크와 혼동되지 않게 톤을 분리

## 1.5) 비율/출력(16:9 기준)

- 프리뷰/썸네일/타임라인의 기본 비율은 **16:9**로 통일
- 카드 썸네일은 “포스터(세로)”보다 “프레임(가로)”로: 영상 제작 스튜디오 인상 강화

## 1.6) 사용자 선택(토글)로 제공하기

- “짙은 네이비/차콜 + 네온 하이라이트” 같은 강한 무드는 **Studio Mode에서만** 제공
- 필름 그레인/비네팅 같은 분위기 효과는 **Atmosphere 토글(Clean ↔ Filmic)** 로 분리(사용자가 꺼서 깔끔하게도 사용 가능)

## 2) 타이포(한글 기준) 위계

- 한국어 올인 전제에서, 가장 큰 퀄리티 차이는 “서체/위계/줄간격”에서 남.
- 추천 원칙:
  - 페이지 타이틀(대시보드/프로젝트/씬 편집) = 28~32px, 굵기 확실히
  - 섹션 타이틀 = 16~18px
  - 본문 = 14~15px, 행간 넉넉히
  - 숫자/시간(0:00 등) = 모노스페이스 계열로 분리하면 “편집툴” 감성 강화

## 3) 간격/라운드/그림자(“툴”처럼 보이게)

- 라운드는 지금처럼 크면 “귀엽다”로 가기 쉬움.
- 권장:
  - 큰 카드/패널: radius 16
  - 버튼/칩/배지: radius 10~12
  - 노드(캔버스): radius 14 정도로 통일 + 상태만으로 차별화

그림자:

- 얕은 드롭섀도우 1개 + 글로우 1개(강조 상태에서만)
- “핑크 테두리”를 여러 겹 두르는 건 피하고, 강조는 **빛(글로우)** 로 처리

## 4) 컴포넌트 규칙 (일관성 체크리스트)

- 버튼
  - Primary: 채움(핑크) + 아이콘(선택) + 로딩 상태(스피너)
  - Secondary: 아웃라인 + hover 시만 약한 fill
  - Tertiary: 텍스트 버튼
- 배지/상태
  - 텍스트만 금지: 아이콘 + 컬러 + (가능하면) 미세한 모션
- Empty 상태
  - “없습니다” 한 줄 금지: 다음 행동(CTA) + 짧은 설명 + 예시(목업) 1개

## 5) 씬 편집(캔버스) 전용 룩

- 캔버스 배경은 “작업대”처럼:
  - 점선 그리드 대신 미세한 노이즈/가이드 라인 + 약한 비네팅(vignette)
- 노드는 “장비 패널”처럼:
  - 상태 LED(좌상단 작은 점)
  - RUNNING 시 스캔 라인
  - SUCCEEDED 시 썸네일 blur→sharp

## 6) 데모 임팩트 포인트 3개

1) 프로젝트 상세에서 “다음 할 일” 한 줄 + 단 하나의 Primary CTA
2) 씬 편집에서 “노드 상태 변화”가 색/모션으로 바로 보이기
3) 타임라인에서 “클립이 들어오는 순간” 공유 요소 전환(확대/이동)
