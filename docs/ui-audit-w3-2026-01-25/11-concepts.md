# 11) 컨셉/모드별 피드백 가이드 (사용자 선택형)

요청 반영: “이렇게 바꿔라” 단일 해답이 아니라, 사용자가 선택할 수 있는 **모드/컨셉 기반**으로 피드백을 나눕니다.

## A. Bright Studio (Default, Light)

목표: 밝고 친근하지만 “툴”처럼 정돈된 영상 제작 스튜디오.

- 배경: 따뜻한 오프화이트/핑크 그레이
- 패널: 한 톤 어두운 회색으로 영역 분리(카드 남발 금지)
- 강조색: 핑크는 Primary CTA 1곳에 집중
- “툴 언어”: 타임코드/해상도/길이/상태를 곳곳에 노출(16:9 기준)

Default 적용 화면:

- 랜딩/로그인/대시보드/프로젝트 상세(기본)

## B. Studio Mode (Optional, Dark Toggle)

목표: 몰입/프로툴 무드. “짙은 네이비/차콜 + 네온 하이라이트” 같은 분위기는 **이 모드에서만** 제공.

- 배경: 잉크/차콜
- 패널: 깊은 회색 + 얕은 보더(구획이 또렷)
- 강조색: 핑크/코랄은 “네온 하이라이트”(선택/포커스에서만 글로우)
- 모션: 상태 변화(렌더링/완료)가 더 드라마틱해도 OK(과한 반복은 금지)

Default 적용 화면:

- 씬 편집, 타임라인 (상단바 우측 토글)

## Shared Toggles (Optional)

- Theme: `Bright Studio` ↔ `Studio Mode`
- Atmosphere: `Clean` ↔ `Filmic` (grain/vignette/scanline style effects on/off)
- Motion: `Reduced Motion` (accessibility / motion-sickness)

## How To Use This Doc

For key production pages, proposals are split as:

- Default (Bright Studio) layout decisions
- Alternatives (toggles / Studio Mode / Atmosphere)
