# 03) 대시보드 (`/dashboard`) + 새 프로젝트 모달

스크린샷(1440x900):

- 대시보드(빈 상태): `screenshots-1440x900/02-dashboard-empty.png`
- 새 프로젝트 모달: `screenshots-1440x900/03-project-create-modal.png`

## 현재 관찰

- “My Projects / All Projects” 구분은 직관적.
- 빈 상태에서 “아래가 거의 비어 보이는” 문제가 있음(데모에서 허전함).
- 사이드바 아이콘만으로는 기능을 학습하기 어렵고, 상단바는 요소가 많아 시선이 분산됨.

## 뷰포트(데스크톱)로 보니 더 뚜렷한 점 (1440x900 기준)

- 콘텐츠가 좌측에 “작게” 모여 있고, 오른쪽이 크게 비어 보여서 **스튜디오 툴** 느낌보다 “큰 여백의 랜딩/대시보드”처럼 보임.
- 즉, 좁은 뷰포트에서의 ‘타이트함’ 문제보다 **넓은 화면에서의 공간 활용 문제**가 더 큼.

## 디자인 개선 제안

### 1) 빈 상태를 “온보딩 퀘스트”로

지금의 빈 상태는 “없음”만 전달. 해커톤 데모는 “사용법이 바로 보이는 것”이 더 중요:

- “Create New Project” 영역을 단순 점선 박스가 아니라
  - 3-step 카드(예: `1) 프로젝트 생성 → 2) 씬 추가 → 3) 노드 편집`)로 바꾸고
  - 각 스텝을 클릭하면 해당 UI로 스크롤/모달 오픈
- “샘플 프로젝트 1개 생성” 버튼(데모용) 제공하면 시연 안정성이 크게 올라감

### 2) 사이드바의 학습 비용 낮추기

- 아이콘만 있는 네비는 멋있지만, 해커톤 당일 처음 보는 사람이 많음:
  - hover 시 라벨 툴팁은 최소
  - 더 좋은 건 “확장 모드”에서 라벨이 함께 보이도록(이미 Expand 버튼 있음)

### 3) 프로젝트 카드에 “영화 느낌”을 주기

- 카드 썸네일이 “No Preview”로 비어 있을 때도:
  - 그라데이션 + 필름 프레임(상단 타임코드/하단 크레딧)로 대체
  - 진행도(예: `0/3`)는 텍스트만 말고 **짧은 프로그레스 바**로(시각적 즉시성)

### 모드 적용

- Bright Studio(라이트, 기본): 대시보드는 기본 모드로 유지(친근/탐색/관리)
- Studio Mode(다크, 선택): 대시보드까지 다크로 끌고 가면 “친근함”이 떨어질 수 있어 기본 비적용 권장
  - 단, 사용자가 Studio Mode를 켠 상태로 돌아올 수 있으니 최소한의 대비/토큰은 동작하도록만 설계

## 새 프로젝트 모달 개선

### 1) “지금 선택해야 하는 것”만 남기기

- 현재 모달은 폼이 단순하지만, 데모에서는 “AI 시나리오 생성(선택)”이 핵심처럼 보일 수 있음.
- 추천:
  - 기본 모달은 “제목/장르/분위기”까지만 받고 `생성`으로 끝
  - `AI로 씬 초안까지 만들기`는 2단계(생성 후)로 분리 → 시연 플로우가 더 예측 가능

### 2) 마이크로 카피/프리셋

- 장르/분위기 드롭다운에 “추천 프리셋”을 제공(예: `SF + 서사적` 같은 조합)
- 입력 예시(placeholder)보다 한 단계 강하게: “예: 60초 단편, 5씬, 주인공 1명”

## 전환/모션 제안

### 대시보드 로드

- 프로젝트 카드가 있든 없든:
  - 상단 “인사/제목”은 먼저 등장(0ms)
  - 카드 영역은 120ms 지연 후 **스태거(40ms 간격)** 로 뜨기(데모에서 “완성도” 체감 큼)

### 모달

- 오픈: scale 0.98 → 1.0 + backdrop blur 0 → 6px
  - 닫기: 아래로 12px + 페이드(180ms) (뻣뻣한 느낌 제거)

## 데스크톱 레이아웃 제안(>=1280px)

“읽기 영역(max-width)”을 유지하면서도, 오른쪽 여백을 **스튜디오 정보 패널**로 채우면 인상이 확 바뀜.

- 좌측(메인): 프로젝트 카드/리스트
- 우측(보조 패널, sticky):
  - `최근 작업(최근 편집한 씬/프로젝트)`
  - `Render Queue 요약(대기/진행/완료)`
  - `데모 빠른 시작(샘플 프로젝트 생성/가이드)`

이렇게 하면 “넓은 화면에서 허전함”이 사라지고, 자연스럽게 “AI 영상 제작 툴”처럼 느껴짐.
