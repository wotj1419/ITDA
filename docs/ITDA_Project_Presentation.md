## 1. 프로젝트 개요

### 서비스명
**ITDA (잇다)** - AI Movie Studio

### 한 줄 소개
AI 영화 제작자들이 **기획부터 완성까지 전체 워크플로우**를 하나의 플랫폼에서 진행할 수 있는 **AI 영화 제작 스튜디오**

### 프로젝트 기간
**6주** (2026.01 ~ 2026.02)

### 타겟 사용자
| 페르소나 | 특징 | 니즈 |
|----------|------|------|
| 🎬 AI 영화 제작자 | AI 도구에 관심 많은 크리에이터 | 아이디어를 빠르게 영상으로 구현 |
| 🎥 인디 영화 감독 | 저예산 창작 활동 감독 | 비용 없이 영화 컨셉/프로토타입 제작 |
| 👥 콘텐츠 팀 | 2-3명 협업 영상 제작 팀 | 원격으로 아이디어 공유 및 협업 |

## 4. 주요 기능

### 4.1 기능 개요

| 기능 | 설명 | 구현 상태 |
|------|------|-----------|
| **사용자 인증** | 회원가입, 로그인 (JWT 기반) | ✅ 완료 |
| **프로젝트 관리** | 프로젝트 생성, 씬 관리, 멤버 초대 | ✅ 완료 |
| **AI 시나리오 생성** | 키워드 → 시나리오 아이디어 자동 생성 | ✅ 완료 |
| **오브젝트 시트** | 캐릭터/소품 레퍼런스 이미지 생성 | ✅ 완료 |
| **노드 기반 씬 편집** | Vue Flow 캔버스로 마스터→샷→영상 흐름 시각화 | ✅ 완료 |
| **AI 이미지 생성** | Gemini API로 스토리보드 이미지 생성 | ✅ 완료 |
| **AI 영상 생성** | Google Veo 3.1로 Image-to-Video 변환 | ✅ 완료 |
| **타임라인 편집** | 씬별 영상 클립 순서 조정 및 병합 | ✅ 완료 |
| **실시간 협업** | WebRTC 화상통화 + 화면공유 | ✅ 완료 |

### 4.2 노드 기반 워크플로우

```
┌─────────────────────────────────────────────────────────────────┐
│  📖 씬 헤더 (읽기 전용)                                          │
│     제목과 스토리 설명 표시                                       │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
              ┌─────────────────────────────────┐
              │  🎬 마스터 이미지                │
              │     씬의 기준이 되는 와이드 샷     │
              │     • AI 프롬프트 자동 생성        │
              │     • 스타일/시간대/분위기 설정     │
              └────────────────┬────────────────┘
                               │
                    ┌──────────┴──────────┐
                    ▼                     ▼
            ┌───────────────┐     ┌───────────────┐
            │  📐 그리드 v1  │     │  📐 그리드 v2  │  ← 분기 실험 가능
            │     2x3       │     │     3x3       │
            └───────┬───────┘     └───────────────┘
                    │
               ┌────┴────┐
               ▼         ▼
         ┌──────────┐ ┌──────────┐
         │ 📷 샷 A  │ │ 📷 샷 B  │
         │ 클로즈업  │ │ 오버더숄더 │
         └─────┬────┘ └──────────┘
               ▼
         ┌──────────┐
         │ 🎥 영상 A │
         │  ★ 확정  │  ← 타임라인에 확정된 영상
         └──────────┘
```

### 4.3 2단계 영상 병합

```
┌─────────────────────────────────────────────────────────────────┐
│  STEP 1: 씬 타임라인 (씬 편집 화면)                               │
│                                                                 │
│  ┌────────┐ ┌────────┐ ┌────────┐                               │
│  │ 영상A  │ │ 영상B  │ │ 영상C  │   → [씬 영상 생성]              │
│  │  3초   │ │  4초   │ │  3초   │                               │
│  └────────┘ └────────┘ └────────┘                               │
│                    ↓                                            │
│            씬 단위 병합 영상                                      │
└─────────────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────────┐
│  STEP 2: 프로젝트 타임라인 (별도 화면)                            │
│                                                                 │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐                │
│  │  씬 1   │ │  씬 2   │ │  씬 3   │ │  씬 4   │ → [최종 병합]   │
│  │  10초   │ │  12초   │ │  15초   │ │  8초    │                │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘                │
```

### 6.2 기술 선택 이유

| 기술 | 선택 이유 |
|------|-----------|
| **Vue 3** | Composition API로 코드 재사용성 향상, 가벼운 번들 사이즈 |
| **Vue Flow** | 노드 기반 UI 구현에 최적화, 직관적인 워크플로우 시각화 |
| **Spring Boot** | 안정적인 엔터프라이즈급 백엔드, 풍부한 생태계 |
| **WebSocket** | 실시간 알림 및 협업 기능 지원 |
| **Redis Streams** | AI 작업의 비동기 처리, 안정적인 작업 큐 |
| **Gemini + Veo** | Google Cloud AI 통합, 고품질 이미지/영상 생성 |
| **FFmpeg** | 안정적인 영상 처리, 다양한 포맷 지원 |
