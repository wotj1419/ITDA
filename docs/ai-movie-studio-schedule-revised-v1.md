## ✅ MVP Definition of Done (3주차 종료 기준)
- 로그인/회원가입
- 프로젝트 생성 → AI 시나리오 → 씬 자동 생성
- 씬 편집(Vue Flow): 마스터/그리드/샷/영상 노드 생성 및 상태 표시
- AI 이미지/영상 생성(Job) + 완료/실패 실시간 반영(WS)
- 영상 확정 → 타임라인 반영 → **최소 병합(무오디오, concat)** → 다운로드

> ⚠️ MVP 병합은 “기능적으로 동작”을 우선: 720p/H.264/오디오 없음/트랜지션 없음.  
> 성능 최적화·고급 편집은 4주차 이후로 미룸.

## 🎓 학습 기회 요약 (수정 반영)

### ✅ 공통(전원, 기본 소양)
- **Redis Streams 기반 Job Queue**: consumer group / ACK / pending / 재처리 개념
- **Worker 패턴(Job lifecycle)**: queued→running→succeeded/failed, retry/idempotency, timeout, WS 알림과 폴링 fallback
- **실시간 이벤트 모델**: job.done/job.failed 스키마 합의, FE 상태 반영 패턴
