## 📋 문서 배경 (맥락)

### 논의 요약

1. **프로젝트 기간**: 총 6주, 1~2주차는 기획/문서 작업 완료
2. **팀 구성**: 6명 (풀스택 1, BE 3, FE 2)
3. **전략**: Lead(강보승)가 핵심 MVP 스켈레톤을 빠르게 완성 → 팀원들이 확장
4. **MVP 목표**: 3주차 말 (01/23 금) - 핵심 워크플로우 동작
5. **일정 기준**: 평일만 (주말은 다음 주 일정 당겨오기만 가능)

### 주요 결정사항

| 항목 | 결정 |
|------|------|
| 인증 | 강보승이 스켈레톤 직접 구현 |
| AI Job Queue | Worker 패턴을 3명이 분담 (이용호-이미지, 김은서-영상, 장현준-FFmpeg) |
| WebRTC | 5주차에 김은서+장현준(BE) + 박재서+이진원(FE) |
| 인프라/CI/CD | 이용호 담당 |
| 학습 기회 | 단순 CRUD만 하지 않도록 각자 새로운 기술 경험 배정 |
