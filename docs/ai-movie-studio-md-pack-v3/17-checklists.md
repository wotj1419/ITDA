# 17. 체크리스트(테스트/데모)

## 3주차 MVP E2E 체크리스트
- [ ] 로그인/회원가입
- [ ] 프로젝트 생성
- [ ] 시나리오 생성 → 씬 자동 생성
- [ ] 씬 편집 화면 진입(Vue Flow 렌더)
- [ ] 마스터 이미지 생성 Job 요청 → 완료 반영(WS)
- [ ] 샷/영상 생성 Job 요청 → 완료 반영(WS)
- [ ] 영상 확정(confirm) → 타임라인 반영
- [ ] 병합(concat) Job 요청 → 다운로드 URL
- [ ] 실패 Job 재시도 1회

## 4주차 안정화 체크리스트
- [ ] 리그레션 테스트 문서화
- [ ] 오브젝트 시트 생성/CRUD
- [ ] 멤버 초대/권한
- [ ] 업로드 presigned URL
- [ ] Worker pending/timeout 기본 대응

## 5주차 협업 체크리스트
- [ ] 플로팅 협업 바가 라우트 이동해도 유지
- [ ] 음성 통화 참여/퇴장/재연결
- [ ] 채팅 송수신
- [ ] Presence(누가 어떤 화면/씬)
- [ ] Cursor/Selection 표시
- [ ] Soft Lock(편집 충돌 유도 방지)

## 데모 시나리오(권장)
1) 혼자 E2E 완주(3주차 MVP)
2) 두 명이 같이 접속
   - 통화 연결
   - 한 명이 노드 선택/편집 → 다른 사람 화면에서 커서/선택 표시
   - 같은 노드 편집 시도 → Soft Lock 경고
- [ ] Worker pending/timeout 기준 정리

## 5주차 협업 기능 체크리스트
- [ ] 플로팅 협업바(접기/열기)
- [ ] 음성 통화 참여/퇴장
- [ ] 마이크 on/off
- [ ] 통화 유지(라우트 이동해도 끊기지 않음)
- [ ] 네트워크 끊김 후 재연결
- [ ] 채팅 전송/수신
- [ ] Presence(누가 어느 씬/화면인지)
- [ ] Cursor/Selection 표시
- [ ] Soft Lock 경고/표시

## 6주차 배포/데모 체크리스트
- [ ] 운영 배포(릴리즈 태깅)
- [ ] Swagger 문서
- [ ] 데모 시나리오 리허설(1회)
- [ ] 장애 시 fallback(폴링)
