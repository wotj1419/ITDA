     AI Movie Studio - Vue Frontend MVP 구현 계획

     개요

     - 목표: HTML/CSS 디자인 레퍼런스를 Vue 3 애플리케이션으로 변환
     - 기술 스택: Vite + Vue 3 (Composition API) + Pinia + Vue Router +
     TypeScript
     - 데이터: Mock 데이터로 먼저 개발, 나중에 실제 API 연동

     cd itda-frontend
     npm create vite@latest ams -- --template vue-ts
     cd ams
     npm install
     npm install vue-router@4 pinia @vueuse/core lucide-vue-next

     export interface Scene {
       sceneId: number;
       title: string;
       description?: string;
       order: number;
       status: 'DRAFT' | 'IN_PROGRESS' | 'COMPLETED';
     }

     export interface Node {
       nodeId: number;
       type: 'SCENE_HEADER' | 'MASTER' | 'GRID' | 'SHOT' | 'VIDEO';
       parentNodeId?: number;
       prompt?: string;
       status: 'PENDING' | 'RUNNING' | 'SUCCEEDED' | 'FAILED';
       contentUrl?: string;
       position: { x: number; y: number };
     }

     4. Pinia 스토어 설계

     auth.ts

     - state: user, accessToken, isAuthenticated
     - actions: login(), logout(), fetchMe()

     project.ts

     - state: projects, currentProject, members
     - actions: fetchProjects(), fetchProject(), createProject()

     scene.ts

     - state: scenes, currentScene, nodes
     - actions: fetchScenes(), fetchNodes(), updateNode()

     ui.ts

     - state: modals, toasts, sidebarExpanded
     - actions: openModal(), closeModal(), showToast()

     ---
     5. CSS 마이그레이션 전략

     1. CSS 변수 유지 - :root 변수 그대로 사용
     2. 컴포넌트별 scoped CSS - Vue SFC의 <style scoped> 활용
     3. 유틸리티 클래스 - flex, gap, margin 등 그대로 유지
     4. Lucide Icons - lucide-vue-next 패키지 사용
